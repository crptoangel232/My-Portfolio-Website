# My Portfolio Website

My personal portfolio website with an animated login page.

## Features

- Animated boy coding at a desk with a backpack
- Floating code symbols ( </>  { }  ()  []  $ )
- Typing animation on the laptop screen
- Clean login form with social buttons
- Responsive design for mobile and desktop
- Pure HTML and CSS (no JavaScript needed)

## Tech

- HTML5
- CSS3 animations
- No frameworks, no dependencies
